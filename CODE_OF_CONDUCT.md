# Code of Conduct

Participation in this repository should be professional, evidence-led, and respectful. Debate architecture, authority, assurance, and implementation choices directly; do not attack contributors.

Unacceptable conduct includes harassment, discrimination, deliberate misrepresentation of evidence, disclosure of private information, and sustained disruption of project work.

Report concerns privately to the repository maintainer through the contact channels listed on the GitHub profile. Reports will be reviewed with attention to safety, proportionality, and procedural fairness.

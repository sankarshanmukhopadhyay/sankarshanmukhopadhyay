## Publication process

Completed weeks are collected on Mondays in UTC, using a GitHub Actions workflow which creates a reviewable, DCO-signed pull request. Nothing publishes automatically to `main`. Weeks without observed activity still produce an explicit report. Report numbers are observational, restricted to merged PRs authored by `sankarshanmukhopadhyay` in the two stated repository-owner scopes.

The archived October reports are a **manually curated backfill**. Later scheduled reports are deterministic activity reports, with qualitative synthesis added during review. See methodology for limitations.

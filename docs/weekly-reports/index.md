## Publication process

Completed weeks are collected on Mondays in UTC, using a GitHub Actions workflow which creates a reviewable, DCO-signed pull request. Nothing publishes automatically to `main`. Weeks without observed activity still produce an explicit report. The October backfill counts merged PRs in the two owner scopes. Operational reports use a separate versioned activity ledger of authored PR and issue lifecycle events in portfolio and external repositories. Review and merge remain required before publication.

The archived October reports are a **manually curated backfill**. Scheduled and manual catch-up runs generate missing completed weeks and update this index in the same reviewable PR. Until those proposals are merged, the operational archive remains unpublished. See methodology for limitations.

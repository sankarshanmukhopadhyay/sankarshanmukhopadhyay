## Assurance claim

Portfolio status is not self-certifying. The registries state intended authority and lifecycle; repository-level tests and release evidence remain authoritative for implementation claims. Ecosystem observations may nominate review questions, interoperability experiments may produce bounded composition evidence, and assurance findings may drive corrective review, but none of these mechanisms silently changes normative or portfolio authority.

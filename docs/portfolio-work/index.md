# Portfolio Work Queue

The live queue is generated from governed portfolio metadata plus current GitHub Issue and pull-request evidence during the GitHub Pages build.

> This is derived planning evidence, not project authority. Source repositories retain authority over goals, implementation, normative content and releases.

## Work now

The published GitHub Pages build replaces this source placeholder with the current ranked queue. If you are reading this file directly in the repository, use the [published Portfolio Work Queue](https://sankarshanmukhopadhyay.github.io/sankarshanmukhopadhyay/docs/portfolio-work/) for the live view.

## What the queue exposes

- strategic priority independent of effort;
- highest-leverage ready work;
- time-boxed views from ≤15 minutes through one day;
- explicit blockers and external waiting;
- consequential work requiring judgment;
- a separate maintenance lane so dependency noise does not dominate strategic work;
- machine-readable evidence in `data/portfolio-work-queue.json`.

See the [methodology](methodology.md) for scoring, authority boundaries, confidence, falsification rules and limitations.

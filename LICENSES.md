# Licensing

This repository contains both executable software and authored portfolio/governance content. They use different licences unless an individual file states otherwise.

| Material | Licence | Examples |
|---|---|---|
| Software and machine-executable artefacts | [Apache License 2.0](LICENSE-CODE) | Python scripts, test software, JavaScript, JSON Schemas, GitHub Actions workflows, executable configuration |
| Documentation and authored content | [CC BY-NC-SA 4.0](LICENSE-CONTENT) | Markdown documentation, diagrams, governance text, portfolio analysis, explanatory material |

## Boundary rules

- A file that is primarily executable software or a machine-executable validation contract is covered by Apache-2.0.
- A file that is primarily authored prose, documentation, a diagram, or governance material is covered by CC BY-NC-SA 4.0.
- Generated evidence or reports inherit the licence of the producing artefact unless the generated file states otherwise.
- Third-party or adapted-upstream material retains its own upstream licence and attribution requirements where applicable.
- Individual repositories linked from this profile retain their own licence terms; this file does not relicense them.

When reuse crosses both categories, comply with both applicable licences for the material actually reused.

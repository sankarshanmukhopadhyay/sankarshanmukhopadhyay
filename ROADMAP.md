# Portfolio Roadmap

## Current objective

Operate the public profile as a governed portfolio with explicit authority, provenance, lifecycle, adoption, interoperability, observation, and assurance controls.

## Near term

1. Keep flagship, supporting, adapted-upstream, and upstream-reference classifications aligned with public repository state.
2. Complete baseline validation and evidence commands across original flagship repositories.
3. Publish the governance-to-assurance, agent authority-control, interoperability, and TRQP evidence paths.
4. Record fork-local contribution status without implying upstream adoption.
5. Maintain the implemented GitHub account-discovery control so newly public repositories receive an explicit disposition without auto-enrolment.
6. Add documentation-freshness checks that compare governed public surfaces with the canonical repository register.

## Next capability milestones

- **Governance-to-Evidence demonstration:** GAAM, TSMM, TIS, PolicyMesh, and assurance tooling.
- **Agent Authority-Control Plane demonstration:** Agent Registry Protocol, policy execution, schemas, APIs, revocation, and retained decision evidence.
- **Trust Protocol Interoperability path:** ecosystem signal -> human case admission -> invariant/negative testing -> evidence -> candidate upstream feedback.
- **Trust Registry Assurance pipeline:** security profile -> implementation -> conformance -> retained evidence -> assurance conclusion.
- **RAHP assurance path:** persona/scenario -> risk/harm -> controls/guardrails -> assurance tests -> finding disposition -> remediation/feedback.
- **Upstream contribution ledger:** explicit fork-local work, contribution state, and accepted changes without implied upstream adoption.

## Promotion gate

A capability milestone is complete only when another implementer can reproduce the documented command, obtain the expected evidence, identify the governing authority for every normative artefact, distinguish original work from upstream-derived work, and determine which findings have enforcement or remediation authority.

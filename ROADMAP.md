# Portfolio Roadmap

## Current objective

Operate the public profile as a governed portfolio with explicit authority, provenance, lifecycle, adoption, and assurance controls.

## Near term

1. Keep flagship, supporting, and upstream-fork classifications aligned with public repository state.
2. Complete baseline validation and evidence commands across original flagship repositories.
3. Publish the governance-to-assurance, agent authority-control, and TRQP evidence paths.
4. Record fork-local contribution status without implying upstream adoption.
5. Add automated external repository resolution and documentation-freshness checks.

## Next capability milestones

- Governance-to-Evidence demonstration using GAAM, TSMM, TIS, and assurance tooling.
- Agent Authority-Control Plane demonstration using ARPA profiles, schemas, APIs, and policy enforcement.
- Trust Registry Assurance pipeline from security profile through retained evidence.
- Upstream contribution ledger for fork-local work and accepted changes.

## Promotion gate

A capability milestone is complete only when another implementer can reproduce the documented command, obtain the expected evidence, identify the governing authority for every normative artefact, and distinguish original work from upstream-derived work.

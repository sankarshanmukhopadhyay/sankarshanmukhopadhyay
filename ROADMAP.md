# Portfolio Roadmap

## Current objective

Convert the public profile from a catalogue of repositories into a governed portfolio with explicit lifecycle, authority, adoption, and assurance controls.

## Near term

1. Verify repository classifications against current public state.
2. Complete baseline files and validation commands across all flagship repositories.
3. Publish the TRQP adoption path and agent-governance boundary map.
4. Add automated broken-link and documentation-freshness checks.

## Next capability milestones

- Delegated Authority Assurance demonstration.
- Trust Registry Assurance pipeline.
- Governance-to-Evidence pipeline.

## Promotion gate

A capability milestone is complete only when another implementer can reproduce the documented command, obtain the expected evidence, and identify the governing authority for every normative artifact.
